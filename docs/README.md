# Thought Pins Documentation

The repository root contains the stable engineering contracts used most often.
Supporting material is grouped here so application and store-submission surfaces
remain easy to audit.

- `product/`: product behavior and personality contracts.
- `architecture/`: memory, mobile API, storage, and platform decisions.
- `operations/`: deployment, rollback, and release procedures.
- `release/`: store policy, privacy, review, and versioning evidence.

Public legal text is maintained separately in `site/`. Store-console evidence
lives in `deploy/store/`. Founder-only runtime material remains under `founder/`
and is excluded from public and native release artifacts. Historical design
handoffs are retained outside this repository in `Thought Pins Development Archive`.
