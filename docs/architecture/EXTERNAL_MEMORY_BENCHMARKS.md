# External Memory Benchmarks

## Purpose

Thought Pins evaluates retrieval against independently labeled data in addition
to its deterministic product fixtures. These benchmarks answer narrow,
measurable questions: can the ranker recover the correct historical session,
preserve a named speaker, and resist plausible but incomplete social decoys?
Answer correctness and production latency require separate measurements.

The dataset manifest is `deploy/quality/memory-benchmarks.json`. Downloads live
under ignored `.tmp/benchmark-corpora/`; no third-party corpus is committed to
the product repository or copied into user memory.

`scripts/prepare_memory_benchmarks.py` verifies the LongMemEval digest and Git
revisions before an evaluation starts. Missing, mismatched, unlicensed, or
usage-incompatible sources fail closed.

## Split Discipline

Cases are assigned by a stable SHA-256 bucket over their source identity:

- Buckets 0-3: calibration train.
- Bucket 4: calibration validation.
- Bucket 5: final holdout.
- Buckets 6-9: diagnostics only.

The temporal and social coefficients are selected without reading holdout
labels. Temporal weight uses LongMemEval train/validation MRR and nDCG. Social
weight must pass LitBank train/validation and a deterministic adversarial suite
containing same-person, same-place, high-star, incomplete-scene, and
unattributed-rumor decoys. Among policies that clear those constraints, the
smallest weight on the best validation plateau wins.

The current selection is:

- Relative-time match: `0.06`.
- Social evidence utility: `0.15`.

The social selection is the smallest tested value that reached at least 0.95
Recall@1 and 0.995 Recall@3 on 640 adversarial cases while retaining perfect
LitBank validation Recall@1 and producing no top-ranked unattributed uncertain
claim. The report is generated by `scripts/calibrate_memory_ranking.py` and
attests `holdout_accessed: false`.

## Results

The July 21, 2026 holdout replay produced:

| Benchmark | Cases | Metric | Baseline | Thought Pins |
| --- | ---: | --- | ---: | ---: |
| LongMemEval | 46 | Recall@1 | 0.8478 | 0.8696 |
| LongMemEval | 46 | MRR | 0.9065 | 0.9174 |
| LongMemEval | 46 | nDCG@10 | 0.9000 | 0.9049 |
| LongMemEval | 46 | Recall@5 / Recall@10 | 1.0000 | 1.0000 |
| LitBank, all speakers | 25 | Recall@1 / MRR | n/a | 1.0000 |
| LitBank, minor speakers | 16 | Recall@1 / MRR | n/a | 1.0000 |
| Project Gutenberg | 300 books | Recall@1 / MRR | n/a | 1.0000 |

The LongMemEval baseline is the benchmark adapter's dependency-free BM25
ranking over the identical candidate sessions. Thought Pins applies the same
production ranking policy used after candidate generation. LitBank candidates
use human speaker annotations and equal starting scores, so the test isolates
identity-aware reranking rather than retrieval-provider behavior.

The public-domain replay evaluated 300 item-header-validated books from 306
catalog attempts, including 182 first-person-dominant passages. Its generated
queries retain source attribution and are useful as a large regression sweep;
because answers are derived from the same held-out passages, this is not an
independently labeled quality estimate.

The first holdout read occurred after the initial `social-episodic-v2`
calibration. A later regression test required a stricter importance gate and a
larger social coefficient selected solely from train, validation, and the
adversarial suite. The post-repair holdout replay above is therefore
confirmatory. A future quality estimate needs a new untouched corpus.

## Reproduction

```powershell
python scripts/prepare_memory_benchmarks.py
python scripts/calibrate_memory_ranking.py --output reports/memory-ranking-calibration.json
python scripts/evaluate_external_memory_benchmarks.py --partition holdout --output reports/memory-external-holdout.json
python scripts/evaluate_social_relevance.py --cases 5000
python scripts/evaluate_public_domain_social_corpus.py --sources 300 --candidate-pool 24
```

The preparation script downloads only sources permitted by the manifest. The
Project Gutenberg evaluator validates official item headers, constrains
redirect hosts, caps response bytes, normalizes its ignored cache atomically,
and fails unless it reaches the requested evaluation sample.

## Limits

- LongMemEval measures evidence-session ranking, not final natural-language
  answer faithfulness.
- LitBank tests published literary dialogue, not the full ambiguity of names in
  a private journal.
- Synthetic scenes are useful adversarial controls but cannot estimate real
  user satisfaction.
- Public-domain passage queries are generated from held-out source text and can
  overstate performance relative to messy shorthand.
- All reported corpus metrics are local, single-process evaluations. Managed
  database, queue, vector, and multi-user latency require separate staging
  proof.
