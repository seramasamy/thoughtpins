# Design explorations

Work that informed the product's look and is kept for reference, not shipped.

`site/` contains only what the service actually serves. These files used to live
there, which meant rejected logo drafts were fetchable on the production domain
and two scratch pages sat in the deployed tree — untidy for anyone reading the
repository, and slightly worse than untidy for anyone browsing the site.

- `logo-candidates/` — the four marks considered before the brain-pin was chosen.
- `logo-review.html` — the side-by-side comparison page used to choose it.
- `home-alt.html` — an alternate homepage concept that lost to the current one.

Open them from disk. Nothing here is linked from the site, referenced by the
application, or included in a release artifact.
