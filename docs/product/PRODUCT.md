# Thought Pins Product Context

## Product

Thought Pins is a private memory layer for ordinary life. A person can talk,
journal, save a reading, import an Obsidian vault, and later recover the right
detail through conversation, recaps, search, or connected memory profiles.

The core experience is chat. Structure should appear as a useful consequence
of natural use, not as a data-entry burden.

## Audience

- People who journal inconsistently but still want durable recall.
- People who collect articles, books, notes, and documents alongside lived
  memories.
- Privacy-conscious users who expect export, deletion, and clear source
  boundaries.
- Returning mobile users operating quickly and often one-handed.

## Aha Moment

Within the first minute, the user says something naturally and sees that
Thought Pins can both respond conversationally and place the detail in the
right kind of memory. Later, an obscure relevant detail returns with its
source and date intact.

## Primary Workflows

1. Talk normally; route conversational chat, journal memories, reminders, and
   source links without requiring commands.
2. Revisit daily, weekly, and monthly journal recaps.
3. Browse people, places, and other recurring entities as memory profiles.
4. Save articles, documents, and notes into reading memory and open the
   canonical original publisher link.
5. Export a portable Obsidian-compatible vault or delete the account.

## Register

- Product surfaces: quiet, efficient, stable, readable, and state-aware.
- Brand surfaces: more expressive typography and composition, but never a
  generic SaaS landing page.
- Default register: product.

## Platform

adaptive

The responsive web app, iOS app, and Android app share information
architecture and behavior while retaining platform-native interaction.

## Response Voice

Warm, specific, calm, and professional. Avoid hype, exclamation-heavy chrome,
clinical database language, and unexplained implementation terms. The user
should see "Reading memory" rather than provider names, retrieval scores,
restricted-access flags, IDs, or storage paths.

## Trust Boundaries

- Journal memories and external reading sources remain distinguishable.
- Stored source text is private user memory and is not rendered on public
  pages or returned by source-list APIs.
- User-facing source links resolve to the canonical publisher page.
- Public web content, official feeds, user-provided text, and user-authorized
  uploads may be processed. Access controls are not bypassed.
- Export, account deletion, maintenance, offline, loading, and failure states
  are product features, not implementation afterthoughts.

## Anti-References

- Generic card-grid SaaS dashboards.
- Beige "AI notebook" themes with ornamental paper effects.
- Purple gradients, glass panels, decorative blobs, and fake social proof.
- Tiny uppercase eyebrows repeated above every heading.
- Raw entity labels, provider names, internal paths, IDs, or access-policy
  diagnostics in normal user views.
- Motion added for spectacle rather than state communication.
